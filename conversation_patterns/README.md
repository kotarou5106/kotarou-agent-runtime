# conversation_patterns

Reusable conversation flow patterns.

- `passive_chat/`: user asks, Agent replies.
- `proactive_chat/`: Agent decides whether to speak first.
- `message_flow/`: inbound and outbound message objects and queues.
- `response_parsing/`: converting model output into reply metadata.

This maps to Prompt Chaining, Routing, Reflection, and Human-in-the-Loop flows.
