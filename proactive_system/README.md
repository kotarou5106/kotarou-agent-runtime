# proactive_system

The Agent's "speak first" system.

- `signals/`: alert, content, and context sources.
- `ranking/`: priority, interruption, and duplicate decisions.
- `decision_loop/`: proactive LLM tool loop.
- `delivery/`: sending, ACK, and delivery bookkeeping.
- `presence/`: user activity and energy model.
- `monitoring/`: proactive state and tick logs.

Current implementation is in `proactive_system`.
